# Example models

`archisurance.xml` is The Open Group's ArchiSurance example model, included as a
real-world round-trip fixture for the AOEF codec. It is distributed by The Open
Group for use with the ArchiMate® specification and was obtained from the
Apache-2.0 licensed [ArchiPulse](https://github.com/DisruptiveWorks/archipulse)
example directory.
